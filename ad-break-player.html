During the break

Pausing and muting only work if adbreak-client.js is running inside your app. Browsers block a parent page from reaching into a cross-origin frame, so there is no way around that part.

The script your app needs 
Save adbreak-client.js to /public in your repo, then add this to your root layout:

  <script src="/adbreak-client.js" defer></script>

Push to GitHub. Vercel redeploys and the dock below will say "Content control ready".

For games and custom players, pause on the event it fires:

  window.addEventListener('adbreak', (e) => {
    if (e.detail.state === 'start') game.pause();
    else game.resume();
  });
Ad slot
Fields 
video     mp4 address — plays for its own length

weight    pick frequency, default 1
impressionUrl / clickUrl   optional tracking beacons

For real 30-second video inventory you want a VAST tag through Google's IMA SDK rather than a display tag. Note that AdSense forbids ads placed around a framed page — if you want programmatic money, put the ad code inside the Vercel app itself, not in this wrapper.

Launch link

Settings travel in the address bar: ?url=…&every=15&len=30&warn=10&kiosk=1. Kiosk hides the dock. Press S for settings, B to fire a break.
